# Traveller character generator (development preview)

Original, non-commercial software under development. This is **not a complete or rules-certified generator**. Some paths stop for source-book adjudication. Do not publish, link from the live tools index, or describe this preview as complete until the release gates in COVERAGE.md are met.

## Run locally

Node.js 22 or newer; no runtime dependencies.

```sh
node tools/character-generator/server.mjs
```

Open `http://127.0.0.1:8781/?api=local`. The server listens only on loopback and provides the separate JSON rules API. `PORT` can select another local port. A static server can instead serve this directory: without `?api=local`, the same API adapter runs the rules module in the browser. No account, telemetry, cloud save, or external data transmission is used.

## Design

- `engine/catalog.mjs`: source identifiers, species, careers, and labels.
- `engine/core-pack.mjs`, `expansion-pack.mjs`, `education-pack.mjs`: original numeric rule representations with source-page references.
- `engine/core-procedures.mjs`: pure procedures for ageing, injuries, benefits, medical bills, and pensions.
- `engine/companion-education.mjs`: pure, source-referenced Companion admission and award rules.
- `engine/audit.mjs`: deterministic before/after mechanical audit detail.
- `engine/session.mjs`: deterministic state transitions and the versioned API. No DOM dependencies.
- `gui/client.mjs`: interchangeable in-process or HTTP API transport.
- `gui/app.mjs`, `index.html`, `styles.css`: accessible, large-control interface and live character sheet.
- `server.mjs`: local HTTP adapter. Not an authenticated production service.

See API.md for the request/response contract and COVERAGE.md for the boundaries of automation.

## Requested options

0-6 boon rolls, score placement/swapping, rerolls below a six-base-score total of 43, and optional extra characteristics. These switches are explicitly identified as optional or house rules. Extra characteristics and species modifiers are excluded from the reroll threshold. Different alien dice formulas cannot be swapped without an explicit GM exception. Boons currently apply to the first N rolls before allocation.

PSI is absent until tested or generated by a species rule. The Zhodani Intendant/Noble option requires GM mode. Species-specific social and psionic rules are separate from optional human characteristics.

The action log is always on. GM edits require a reason and keep the old result. Restoring or replacing an old result appends an action; it does not erase history or rewind the random sequence. Save files include that history. This is a local audit trail, **not cryptographic proof, hidden randomness, or protection against a person rewriting their own file**.

## Data and saves

The browser stores one draft locally. Use **Save character & log** for backups before starting a new character. Import replays and validates the file before replacing the current draft. Unreadable stored drafts are preserved behind recovery controls, with raw backup download and explicit replacement confirmation. Save format 1 is an evolving preview format, not yet a long-term migration guarantee. Keep a printed/exported record when updating versions.

No licensed books, scans, private document links, or borrowed Tremlas code are included. Own the relevant books to resolve source-assisted steps. Character names, notes, and campaign material stay in your browser or local API request and are not sent to the publisher or repository.

## Verification

```sh
node --test tools/character-generator/verification/*.test.mjs
node tools/character-generator/verification/browser.mjs /path/to/playwright
node tools/character-generator/verification/review-browser.mjs /path/to/playwright
node tools/character-generator/verification/expansion-browser.mjs /path/to/playwright
node tools/character-generator/verification/career-smoke.mjs
```

Browser checks require Playwright and an installed browser. Set `CHARACTER_BROWSER_CHANNEL=msedge` to use installed Microsoft Edge. Browser contexts are temporary and do not use an existing signed-in profile. Screenshots and results go to ignored `verification/artifacts/`.
