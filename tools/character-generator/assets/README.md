# Opening artwork

The Human and Vargr portraits are exact crops of the user's approved generated portrait sheet. The Aezorgh portrait is the user's approved generated standalone image. These are illustrative samples, not character data or an inferred gender selection. No Mongoose/Aliens of Charted Space reference-derived Aslan image is included. Aslan retains the same working species controls without a portrait pending a cleared image.

The two decorative SVG scenes are original code-drawn artwork made for this opening screen. They do not contain publisher art or logos. Portraits are presentation-only and are not added to save files.

The illustrated spaceport landscape is an original generated image requested for desktop preview only. Mobile layouts omit the landscape entirely. It contains no supplied publisher reference art.
