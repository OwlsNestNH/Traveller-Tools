Companion movement profile and limits

Traveller Companion Update 2024, printed pp.173–175: six-minute rounds, 648 km per hex, persistent vectors, reverse-initiative acceleration declarations and simultaneous movement. Recorded initiative is manual and persists until edited. There is no automatic roll or per-round reroll. Reserve thrust before movement for evasion/helping gunners; those checks are not resolved here. Manual plotting remains available outside guided declarations.

Range displays use exact Euclidean centre distance internally. Implementation policy: compare continuous distance directly with 1/15/38/77-space band boundaries, equivalent to outward rounding spaces for the table. Same hex is Adjacent/Close; more than one space is Medium; more than 77 is Distant. Optional two-space Short is disabled. Display rounding does not change the band. Hex distance still measures thrust reachability. Zoom changes only the view.

Plot Stop is a continuing, editable braking intent. Each resolved round recomputes a legal digital straight-line reduction using current thrust minus reservations; it never skips rounds or reverses velocity. Zero available thrust coasts with the intent retained. Plotting a new target or Coast cancels it. Reservations carry forward until manually edited. These automation/rounding choices are implementation policies, not additional quoted rules.

No weapons firing, automatic damage/critical effects, missiles, dogfights, flybys or campaign import. No larger-timescale abstraction. Equipment/condition records remain manual. Source drive thrust is a recorded budget; no reaction-fuel or combined-engine automation is added. This page does not read or save campaign data. Profile and API notes · Asset provenance
