What this alpha does — and does not

Try persistent velocity, per-ship thrust, reachable hexes, plotted movement, round advance, and a proportional map. Range labels are abstract hex-step distances from the selected ship; they are not verified range bands or kilometres.

The engine applies a chosen velocity change, moves using the updated velocity, then clears that round’s thrust. That integration order and the thrust-to-hex conversion are prototype assumptions. Precise Mongoose Traveller 2e integration, physical scale, reaction-engine performance and mixed six-minute/six-second combat remain unresolved.

No weapons, damage, missiles, dogfights, crew model or campaign import. This page does not read or save campaign data; reloading starts a fresh sample. Prototype and API notes
