Map help & legend

Selected-ship range bands: Off / On (shaded bands). Boundaries are 1, 15, 38 and 77 spaces (648 km per space); Distant is beyond 77. Same-hex distance is Adjacent/Close; the solid teal ring is Short. Two ships sharing a hex occupy separate selectable diagonal halves. Three or more use a count button and ship chooser. Zoom in for precise half-hex selection, or use the ship list. Sharing a hex does not start a dogfight. Shading is a view aid, not detection or visibility.

Rules, references and limits

Companion movement profile and limits

Traveller Companion Update 2024, printed pp.173–175: six-minute rounds, 648 km per hex, persistent vectors, reverse-initiative acceleration declarations and simultaneous movement. Captain initiative is explicitly rolled or recorded, committed and confirmed by the GM; it is not rerolled each round. Reserve thrust before movement for evasion/helping gunners; eligible direct-fire checks use those reservations. Manual plotting remains available outside guided declarations.

Range displays use exact Euclidean centre distance internally. Implementation policy: compare continuous distance directly with 1/15/38/77-space band boundaries, equivalent to outward rounding spaces for the table. Same hex is Adjacent/Close; more than one space is Medium; more than 77 is Distant. Optional two-space Short is disabled. Display rounding does not change the band. Hex distance still measures thrust reachability. Zoom changes only the view.

Plot Stop is a continuing, editable braking intent. Each resolved round recomputes a legal digital straight-line reduction using current thrust minus reservations; it never skips rounds or reverses velocity. Zero available thrust coasts with the intent retained. Plotting a new target or Coast cancels it. Reservations carry forward until manually edited. These automation/rounding choices are implementation policies, not additional quoted rules.

Eligible beam/pulse laser firing, sand, Hull damage and bounded critical effects resolve explicitly. Other system effects and unsupported configurations require GM handling. Missiles, point defense, dogfights, flybys and campaign import remain outside automatic resolution. No larger-timescale abstraction. Equipment/condition records remain manual. Source drive thrust is a recorded budget; no reaction-fuel or combined-engine automation is added. This page does not read or save campaign data. Profile and API notes · Asset provenance
