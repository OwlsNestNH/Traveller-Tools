# Build status

The Vehicle Builder retains its construction features, equipment reference tables, source citations, local save/import/export, mixed passenger seating and printable records.

The 99 catalogue test designs and detailed vehicle data were removed from the current publication on October 3, 2026. Historical aggregate findings remain in the catalogue and Hull/Structure summary reports and CSV files. These are earlier test results, not verified designs or official errata; catalogue comparisons cannot be rerun without the removed fixtures.

The remaining construction, mechanics, Appendix I, seating, Hull/Structure and rendering tests are in source/. Edit source/dist/ and rebuild with source/package_standalone.py when changing the application.
