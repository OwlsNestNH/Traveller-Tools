Recent changes

November 3, 2026 · Feature help and full builder audit

  • Feature Info popups now explain actual handling/speed/range changes, costs, trade-offs, prerequisites, conflicts and current fitting state, replacing terse catalogue one-liners.
  • Added useful help for numeric allocations, armour transfers, passenger groups, weapon fittings, equipment quantities and search filters throughout the builder. Bay quantities are labelled in carried-vehicle shipping tons to match the existing calculation.

November 3, 2026 · Option explanations

  • Info popups now explain the purpose, selected specification and key limits of each equipment option and construction dropdown, with existing source references.
  • Explanations update when a dropdown choice changes; keyboard and touch controls use the same popups.

Compact worksheet interface

November 3, 2026

  • Compact vertical construction rows and dropdowns replace large feature and equipment cards.
  • Click or tap Info for explanations and source references; Escape or Close returns to the builder.
  • Live totals, construction checks, JSON designs and browser saves retain their existing calculation engine and format.
