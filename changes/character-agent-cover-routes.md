# Agent cover routes

Adds bounded Core Agent Event 8 and Vargr Agent Event 9 procedures with explicit cover selection and specialist training, source-page provenance, originating Agent accounting and queued source interruptions.

Core success borrows a Rogue/Citizen Event plus training; Vargr success grants training and next Agent advancement DM+2 without an Event. Failure borrows the selected cover's Mishap. No cover career is entered or credited. Nested stay exceptions and terminal injury cancellation are preserved.

Vargr automation covers the other eight native Vargr careers plus Core Drifter (Aliens 2026 pp. 186, 189). Cross-cultural and optional Companion covers remain a documented source/referee boundary. Deferred Zhodani behavior and public exclusion are preserved.

Verification: dedicated API, audit, atomic rejection, idempotency, import/replay, nested Mishap and fatal injury tests; retained 45-career smoke; new browser CI suite covering static/HTTP transports and mobile/desktop widths. Browser execution is delegated to CI because local Chromium launch is prohibited in the cloud executor. No publication or rules revision change is included.
