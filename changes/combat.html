Recent Changes

Published updates.

October 29, 2026

  • Gunnery declarations now cycle through turrets, select an installed weapon type and record an attack target, laser point-defense reservation, sand reservation or Hold fire. Ships commit from lowest to highest initiative under a labelled home rule; committed choices stay locked and survive save/load. After all eligible ships commit, the existing manual resolution step becomes available. Declaration applies no firing, ammunition use, damage or automatic defenses. Unsupported weapon types and non-turret mounts remain manual.

October 28, 2026

  • Captain opening initiative now guides each ship through explicit rolls and commits, followed by GM confirmation into Pilot movement. Simplified crews use their experience rating as skill; detailed crews use recorded skills. Missing naval Tactics requires an explicit modifier, recorded Effect or Skip choice. Committed rolls retain their original dice and inputs, with a warning after crew or thrust changes; legacy/manual totals are identified without inventing a breakdown. Release #196
  • Wider Ship Details gives equipment and Crew/Power more room while keeping Save and Cancel accessible. Evasive action and Help gunners use numbered thrust sliders sharing the available budget; Apply reservations remains explicit. Release #194
  • Major setup sections use full-width Expand/Collapse bars. Read-only explanations and source information open in dismissible information popups, including Ship Details and Add Ship Preview, without committing edits. Release #193
  • Encounter ships appear above the command toolbar with Details, Focus Ship and Add Ship controls. The oval map has station sectors, with selected Ship Status and station commands alongside it. Condition and Power popups preserve drafts during resizing; crew setup remains available. Sensor mode is recorded in setup and defaults to Active. Release #192

October 27, 2026

  • Optional battle phases now confirm recorded initiative, commit thrust plots lowest-first and move ships together, followed by manual Attacks and Crew Actions acknowledgements. Those acknowledgements do not apply combat effects. Release #191
  • Weapon tech advantages and disadvantages can be edited separately from the base weapon, with compatibility checks, legacy/manual Power preservation and specific unknown-Power explanations. Release #190
  • Roster Details now edits the selected ship in the shared setup sheet, with compact silhouettes, a centered draft preview, and side selection beside Preview. Save and Cancel preserve existing ship state. Release #189
  • M-drive design Power calculation with explicit tech options, recorded/manual overrides and unknown-value preservation. Numeric edits retain the chosen quick weapon loadout. Release #188

October 26, 2026

  • Editable shared ship setup and Details, Custom Ship, software dropdown rows, and aligned capacity/current fields with visible override provenance. Release #187
  • Separate tool changelogs with contact and feedback details, linked below the main launch buttons. Release #186
  • Clearer same-hex and Short-range labels. Two ships sharing a hex can be selected separately; larger groups open a ship chooser. Release #184
  • Unified ship setup sheets and crew skill lists that retain crew identity and legacy records. Release #183
  • Weapon slots and power requirements, with loaded ammunition tracked separately from reserve magazines. Release #182
  • Compact sidebar status and Pilot/Engineer controls, plus a generic Pilot skill-check strip. Sidebar release · Pilot checks

Still to come

Approved remaining work, not released. Some underlying mechanics already exist; these are workflow integration and testing tasks. No release dates are promised.

  • Attack resolution workflow: automatic defenses, missiles, damage, separate stacked criticals and a results display.
  • Remaining crew actions: sensors and electronic warfare, engineering, damage control and changing stations.
  • Complete the end-of-round flow and add printable/saveable after-action reports.
  • Reinforcements that join without resetting committed combat declarations, the Companion Short-range choice of one or two hexes, and deferred layout cleanup. Currently, Add Ship during confirmed combat requires explicitly leaving the workflow, which clears its declaration sequence.
  • Multiplayer and dogfighting remain later stages.
